# 插件使用文档

> 这份文档写给玩家：讲插件是什么、怎么装、出问题怎么办。想自己写插件，看同一窗口里的「开发文档」。

插件是启动器上的扩展功能：可以在左侧导航里加一个自己的页面，也可以改写下载地址、替换界面文字或者弹出通知。插件由你自己安装；某个插件出问题时，只会影响它自己，启动器的其他功能照常可用。

> **从 v1.5.0 起，插件属于实验性功能，默认关闭。** 需要到「设置 → 实验性」打开「启动器插件」，再按提示重启启动器。关闭时所有插件都不会加载，插件商店与插件页也不会出现，但**插件目录与插件数据不会被删除**，重新打开并重启即恢复。

## 1. 安装插件

有三种安装方式，任选一种：

1. 在「发现 → 启动器插件」里找到要用的插件，点「安装」，装好后按提示重启启动器。
2. 在「设置 → 插件」点「安装插件包…」，选一个插件包文件（后缀 `.lumenplugin`）。
3. 点「打开插件目录」，把解压好的插件文件夹直接放进去。

装完要重启启动器，插件才会出现在左侧导航里；脚本类插件没有界面，重启后就直接生效。

## 2. 启用与停用

- 「设置 → 插件」里每个插件右侧都有开关，关掉之后下次启动就不再加载它。
- 开关状态会被记住，想再打开时把开关拨回来、重启启动器即可。
- 停用或删除插件都不会删掉插件自己保存的数据。

## 3. 安全模式

如果某个插件让启动器启动不起来，启动器会自己切到安全模式：所有插件都不加载，其余功能照常。

- 退出安全模式：「设置 → 插件」→「重新启用插件并重启」。
- 被隔离的插件会单独标成「已隔离」，点它右边的「清除隔离」再重启，就会重新尝试加载。
- 只想临时排查是不是插件引起的问题，可以用 `--safe-mode` 参数启动一次。

## 4. 插件页面打不开怎么办

- 先点页面上的「重试」。
- 还是不行就重启启动器；如果一直失败，在「设置 → 插件」里把这个插件停用。
- 页面出错只影响这一个插件，不会影响启动器的其他功能。

## 5. 更新与卸载

- 有新版时，「启动器插件」里的卡片会显示「更新」，点一下就能装上。
- 卸载：「设置 → 插件」→ 插件行右侧的「删除」，或者点「打开插件目录」后删掉对应的文件夹，然后重启启动器。
- 卸载插件不会删掉它保存的数据，重新装回来还能接着用。

## 6. 插件放在哪

插件本身和插件保存的数据都在启动器的数据目录里：

```text
%LOCALAPPDATA%\NovaLink Lumen\LauncherData\plugins\        （插件本体）
%LOCALAPPDATA%\NovaLink Lumen\LauncherData\plugin-data\     （插件保存的数据）
```

升级启动器不会动这两个目录，卸载启动器也不会顺手删掉插件。

## 7. 安全提醒

> 插件运行在启动器进程里，能看到启动器能看到的东西，包括你的游戏账号登录信息。只安装你信任来源的插件，来源不明的不要装。

启动器不会审核插件内容，也没有官方白名单。「启动器插件」商店列出的只是在 GitHub 上公开、打了插件标记的仓库，装之前请自己判断可信度。
