# 测试版（Preview）说明

> 一句话：测试版是**同一个启动器**的提前体验通道，装的是 `1.5.0 Preview`，更新只来自测试版仓库；正式版和测试版不会互相把对方覆盖成另一个通道。

## 1. 什么是测试版

- 测试版用来**提前验证**下一版功能（1.5.0 的插件实验性开关、音乐台进度/音量、快讯图片放大、双通道更新等）。
- 它和正式版是同一个应用、同一套数据目录、同一套账户与实例，不是另一个产品。
- 测试版功能可能还会调整、回退甚至崩溃；追求稳定请用正式版。
- 版本标识：应用内显示 **1.5.0 Preview**；安装包文件版本 `1.5.0.0`；程序内部的信息版本是 `1.5.0-preview.1`（日志与更新检查使用）。

## 2. 与正式版的关系

| 项目 | 正式版 | 测试版 |
|---|---|---|
| 版本示例 | `1.5.0` | `1.5.0 Preview`（内部 `1.5.0-preview.1`） |
| 安装包文件名 | `NovaLinkLumen-WinUI-Setup-1.5.0.exe` | 同名规则（按版本号命名，不区分通道） |
| 更新来源仓库 | `Eric8844/novalink-lumen-releases` | `Eric8844/novalink-lumen-preview` |
| 接受的 Release 标签 | 纯数字，如 `v1.5.0` | 带 `-preview` / `-beta` / `-rc`，如 `v1.5.0-preview.1` |
| 用户数据 | `%LOCALAPPDATA%\NovaLink Lumen\LauncherData` | **同一目录，完全沿用** |

- 两者**不能同时安装**：同一程序目录，装测试版会覆盖正式版的程序文件，装回正式版同理。
- 切换通道靠**重新安装对应通道的安装包**，应用内没有「切换通道」的开关（避免一次误点把稳定用户带到测试版）。
- 账户、实例、设置、插件目录都在同一个数据目录里，换通道不会重建。

## 3. 下载与安装包命名

- 测试版安装包固定发布在 GitHub 仓库 `Eric8844/novalink-lumen-preview` 的 Releases 里。
- 文件名：`NovaLinkLumen-WinUI-Setup-1.5.0.exe`（按版本号命名；同一版本不同通道文件名相同，但只在各自仓库提供）。
- 该仓库**只提供安装包、更新日志和说明，不包含源代码**，也不是开源发布渠道；仓库里的 Release 说明会写清本版包含什么、已知问题。
- 安装方式与正式版一致：双击安装包装到默认目录，已有的账户与实例自动沿用。

## 4. 更新通道规则（不会串台）

通道在**编译时**就写死了，运行时无法被篡改，也不会因为装了什么而改变：

1. 测试版安装包在编译时带上 `NOVALINK_PREVIEW` 常量，更新检查只请求 `Eric8844/novalink-lumen-preview`；
2. 正式版安装包不带该常量，只请求 `Eric8844/novalink-lumen-releases`；
3. 测试版只接受标签里带 `-preview` / `-beta` / `-rc` 的 Release，正式版只接受纯数字标签；不匹配的 Release 会被**直接忽略**并写一条 `updates` 日志；
4. 因此：**测试版收不到正式版更新，正式版也收不到测试版更新**；两个通道不会互相覆盖。

更新检查结果与「是否已是最新」都以当前通道为准。想换通道，只能手动安装另一个通道的安装包（见下一节）。

## 5. 从测试版回到正式版

数据不会丢——卸载器默认保留用户数据：

1. 关闭启动器；
2. 在「设置 → 应用 → 已安装的应用」里卸载 NovaLink Lumen；卸载器问「是否删除启动器数据」时选**否**（默认就是保留）；
3. 到正式版 Release 下载 `NovaLinkLumen-WinUI-Setup-<版本>.exe` 安装；
4. 首次启动自动沿用原来的账户、实例与设置。

如果误选了删除数据，升级前的自动备份仍在 `%LOCALAPPDATA%\NovaLink Lumen\Data_Backup_v<源版本>\`，可用 `NovaLink.Lumen.exe --restore-data-backup` 恢复（详见 [PUBLISHING.md](PUBLISHING.md) 第 8 节“回滚”）。

## 6. 反馈测试版问题

请在测试版仓库的 Release / Issue 反馈，并附上：

- 应用内版本号（关于页显示 `1.5.0 Preview`）；
- 复现步骤（尽量具体到点了哪个按钮）；
- 日志：`%LOCALAPPDATA%\NovaLink Lumen\LauncherData\logs\lumen-<日期>.log` 里对应时间段的几行（含 `[ERROR]` 或 `[WARN]` 的部分最有帮助）；
- 如果问题与插件有关，再附插件 id 与 `plugins\<id>\plugin.json`。

## 7. 常见问题

**Q：测试版会把我踢回正式版吗？** 不会。测试版只检查测试版仓库；只有你手动安装正式版安装包才会回到正式版。
**Q：正式版用户会收到 1.5.0 Preview 吗？** 不会。正式版只接受纯数字标签的 Release，`v1.5.0-preview.1` 会被忽略。
**Q：能同时装正式版和测试版对比吗？** 不能，同一程序目录与数据目录，只能装一个。
**Q：测试版仓库为什么没有源码？** 测试版仓库只作为安装包与更新日志的分发点；源代码不在那里发布。
**Q：测试版的数据能带回正式版吗？** 能，数据目录相同；卸载时保留数据、装回正式版即可。
